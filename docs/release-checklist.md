# Light Canvas 0.1.4 发布范围

| 功能 | 当前实现 |
| --- | --- |
| 画布 | 平移缩放、实时框选、连线、撤销重做、节点查找、主题和背景切换 |
| 分组 | 双击创建、完整拖入、移动、解组和重新排列 |
| 文本 | 手动编辑，接受上游文本、图片或视频帧的生成节点 |
| 图片 | 上传、参考图编辑、文生图、多图参考 |
| 视频 | 上传替换，预留通用视频生成接口 |
| 资产 | 浏览器本地保存上传媒体和下载成功的生成图片，支持 JSON 引用恢复 |
| 接入 | JavaScript ESM、TypeScript 声明、独立 CSS 和自定义 React 节点注册 |

运行 `pnpm typecheck`、`pnpm build`、`pnpm pack:canvas`，并从独立 React 项目安装 tarball 验证包入口。生成接口可使用模拟 Producer 做交互回归，真实调用需使用对应服务的额度和密钥。

## 当前限制

- JSON 导出保留本地资产引用，跨浏览器导入时需要另外传输本地资产。
- 视频帧理解不包含音轨。实际视频生成由宿主接入。
- 本版本面向单人本地画布。PNG 导出、多人协作、视频编辑和整组执行暂未提供。

## 0.1.2

- 支持提示词内的引用标签、键盘选择和直连输入。
- 合并媒体参数，按节点保存比例，支持模型声明的首尾帧和视频选项。
- 生成历史按批次保存，支持预览、设为当前和复制为新节点。

## 0.1.3

- 增加图片和视频节点的当前结果下载。
- 统一重新生成时的加载、错误和取消状态。
- 提供可选兼容后端和统一生成任务接口。

## 0.1.4

- 发布 npm 包 `@infranic/light-canvas`。
- 图片和视频节点调整大小时保持素材宽高比。
